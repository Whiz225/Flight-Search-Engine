# ✈️ SkySearch Flight Engine

A modern, responsive flight search engine built with React. This application demonstrates real-time price tracking, complex filtering, and beautiful data visualization.

## 🚀 Features

### Core Features

- **Smart Flight Search**: Search flights by origin, destination, dates, passengers, and class
- **Real-time Price Graph**: Interactive chart showing price trends with Recharts
- **Advanced Filtering**: Simultaneous filters for price, stops, airlines, and sorting
- **Responsive Design**: Fully functional on mobile, tablet, and desktop
- **Modern UI/UX**: Clean, intuitive interface with smooth animations

### Polish Features

- **Location Swap**: One-click swap between origin and destination
- **Price Trends**: Visualize price history and predictions
- **Flight Details**: Comprehensive flight information including amenities
- **Active Filters**: Clear visual indication of applied filters
- **Loading States**: Skeleton loaders and smooth transitions
- **Error Handling**: User-friendly error messages

## 🛠️ Tech Stack

- **React 18** - Frontend framework
- **Recharts** - Interactive data visualization
- **React Icons** - Icon library
- **CSS-in-JS** - Component-scoped styling
- **Mock API Service** - Simulated flight data (easily replaceable with real API)
